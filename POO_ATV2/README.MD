#  MinhaBiblioteca

## Sobre o projeto

O **MinhaBiblioteca** é um projeto desenvolvido em C# utilizando .NET 10 e ASP.NET Core.

O projeto tem como proposta desenvolver uma aplicação voltada ao gerenciamento de uma biblioteca, aplicando conceitos de Programação Orientada a Objetos (POO) e organização de código.

## Tecnologias utilizadas

- C#
- .NET 10
- ASP.NET Core
- Swagger / OpenAPI
- Swashbuckle.AspNetCore

## Conceitos estudados

- Programação Orientada a Objetos (POO)
- Classes e objetos
- Herança
- Abstração
- Encapsulamento
- Organização em camadas

## Como executar o projeto

### 1. Pré-requisitos

- .NET 10 SDK
- Visual Studio Code
- Extensão C# para VS Code

### 2. Clonar o repositório

```bash
git clone URL_DO_REPOSITORIO
```

### 3. Entrar na pasta

```bash
cd MinhaBiblioteca
```

### 4. Restaurar as dependências

```bash
dotnet restore
```

### 5. Executar o projeto

```bash
dotnet run
```

## Documentação da API

O projeto utiliza Swashbuckle.AspNetCore para oferecer suporte à documentação de APIs com Swagger/OpenAPI.
